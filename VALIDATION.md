# Validation record

Verified in a browser at desktop (1440 × 900), compact window (762 × 640), and mobile (390 × 844) sizes.

- Loading resolves to the rendered 3D landing world.
- Enter the hive animates into the honeycomb interior.
- Queen selection opens facts and awards 20 XP; repeated visits do not duplicate rewards.
- Buzz answers the contextual queen-death follow-up.
- All eight cell specimens can be selected.
- Five unique flower visits enable returning home; completion awards 100 XP.
- All ten quiz questions accept answers, explain them, and advance. A perfect run produces 10/10 and 50 XP.
- All six zones unlock Hive Explorer and the 150 XP bonus.
- All eight honey journey steps complete and unlock Honey Expert.
- Progress survives page reload. Mobile navigation and scrollable panels work.
- Optional WebMCP navigation accepts a valid mode and rejects an invalid mode.
- No application console errors or warnings during these flows.
- Four Node tests pass for content, duplicate rewards, Buzz routing, and safe defaults.
- Production static validation passes for JavaScript syntax, entrypoint references and vendored dependencies.

Performance has not been benchmarked on physical low-end phones. Tamil/Sinhala learning translations, a connected LLM, WebXR AR, and live sensor connections are future integrations; their current limits are labelled in the interface.
